架构与调度规格

[SEC-01 / SPECIFICATION]

线路分组管理

  • 普通网络节点组：满足基础网页浏览与轻量数据流处理。
  • 专线网络节点组：优化跨地域链路抖动与游戏即时传输。
  • 媒体支持节点组：针对主流公开流媒体平台进行路由适配。

订阅连接交付

  • 单账户提供标准 Subscription URI，格式兼容主流解析器。
  • 支持手动拉取配置文件或定时自动更新节点名册。
  • 节点拓扑结构变动通过订阅链接下发，无需重置密钥。

计费与用量规则

  • 流量按自然月或订购周期自动重置，不支持跨周期结转。
  • 超出配额后接入速度按基础策略下调，至下一个周期恢复。
  • 并发设备数由服务网关在线心跳检测控制。

客户端配置与接入步骤

[SEC-03 / DEPLOYMENT]

飞鸟未发布私有封闭客户端软件，服务依托业界主流开源或通用网络代理核心。用户可在对应操作系统中运行支持标准订阅格式的通用客户端，完成订阅导入。

  1. 01

    获取接入凭证

    完成方案订阅后，进入后台“订阅管理”页面，复制个人唯一的订阅链接（URL）或导出二维码。

    • 注意项：请妥善保存专属链接，切勿在公开网络平台分享以防配额盗刷。
  2. 02

    选用适配客户端

    根据设备平台选用通用的协议工具：

    • Windows / macOS / Linux：使用支持内核规则分流的开源桌面客户端。
    • iOS / iPadOS：在应用商店获取适配规则订阅的通用网络调试工具。
    • Android：安装兼容 Clash、Sing-box 或 V2Ray 内核的标准通用客户端。
  3. 03

    配置同步与连接

    将步骤一中获取的订阅 URL 粘贴至客户端的订阅管理或配置（Profiles）窗口中，点击“更新/Download”。

    • 规则推荐：建议分流策略选择“规则模式（Rule）”，由核心识别国内直连与国际转发。
    • 节点切换：列表拉取完毕后，选择延时较低的节点测试连接状态。
  4. 04

    排错与日常维护

    节点不可用时，请首先尝试强制更新订阅以获取最新解析记录，并核查本地系统时间是否与网络标准时间同步。

常见问题处理清单

[SEC-04 / FAQ]
  1. 01

    飞鸟支持在哪些设备上同时运行？

    具体并发限制取决于所购方案：基础版支持 3 台设备，旗舰版支持 5 台设备，团队版支持 20 台设备。在线判定以接入节点的同时活动连接数为准，超出阈值时后接入的设备将无法正常建立通信会话。

  2. 02

    订阅链接导入后节点列表为空或更新超时？

    常见原因包括：本地网络拦截了订阅下载域名；系统代理未完全退出导致冲突；或订阅客户端未开启允许不安全证书选项。建议临时切换网络环境重试，或从控制台下载本地配置文件离线导入。

  3. 03

    按月订阅与按年订阅在功能上有何区别？

    同一等级的套餐（如旗舰版），按年支付与按月支付在节点池访问权限、可用带宽峰值及同时在线设备数上完全一致。年付方案享受总价折让，但不增加每月流量配额上限。

  4. 04

    流量配额用尽后服务会中断吗？

    当月可用流量消耗完毕后，网关将阻断后续转发请求，直到下一个计费周期自动重置。如需提前恢复，可在控制面板按既定价格购买临时流量叠加包或升级到更高规格套餐。

  5. 05

    流媒体解锁服务覆盖哪些范围？

    基础版仅包含常规基础流媒体支持；旗舰版与团队版提供全节点原生流媒体路由优化。由于流媒体厂商风控策略处于动态变化中，服务通过持续调整出口 IP 池进行适配，不保证特定冷门区域媒体的绝对可用。
